# AIOS 仓库路由

| 仓库 | 主要内容 | 常见问题 |
|---|---|---|
| `aios` | AIOS 应用、推理引擎、Model Center 辅助服务、部署配置 | 应用包、推理启动、模型文件和服务配置 |
| `zstack` | 核心 API、资源模型、编排和后端基础逻辑 | API 流程、资源状态、消息和数据库对象 |
| `premium` | 商业 AI 模块和高级后端能力 | 模型服务、推理服务和商业功能条件 |
| `zstack-utility` | 主机 Agent、系统脚本和节点侧动作 | KVM、GPU、驱动、挂载和系统服务 |
| `zstack-ui-next` | 菜单、页面、表单、权限和前端请求 | 页面入口、按钮显示、字段和交互 |

完整功能链路通常需要同时检查前端入口、后端 API、节点侧动作和 AIOS 应用资产。问题分类只决定首查仓库，不限制后续基于证据扩展。

具体业务知识应由钉钉知识库、对应版本源码和已确认研发资料证明。本文件只承担路由，不承担产品事实。
